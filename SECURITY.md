# Security Policy

## Public Data Repository

This repository supports CVCalculator by maintaining public CIA rate data. It is not intended to store private user data, credentials, app signing files, deployment keys, or store credentials.

## Secrets

Do not commit API keys, tokens, passwords, private keys, service-account files, GitHub tokens, Play Store credentials, App Store credentials, or machine-specific local paths.

## Responsible Disclosure

If you find an exposed secret or sensitive file in this repository, please report it through the repository owner rather than opening a public issue with sensitive details.
